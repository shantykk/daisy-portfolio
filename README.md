## How to Launch in VS Code

1. **Download / Extract** this folder.
2. Open **Visual Studio Code**.
3. **File → Open Folder…** and select the `daisy-portfolio` folder.
4. Install the free extension **Live Server** (by Ritwick Dey) if you don’t have it.
5. Right-click `index.html` → **Open with Live Server**.
6. The site will open in your browser at `http://127.0.0.1:5500` (or similar).

### Alternative (no extension)
Simply double-click `index.html` or drag it into a browser.  
(Downloads will still work; some advanced features may be limited under the `file://` protocol.)
